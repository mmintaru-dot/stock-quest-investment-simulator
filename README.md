# MARKET MIND — 本格株式投資シミュレーター

架空企業20社を財務分析し、1,000万円を10年間運用するブラウザゲームです。実在企業・実際の株価は使用していません。

## 起動方法

`ゲームを起動.html` をダブルクリックしてください。インストールや通信は不要です。

## 遊び方

1. 企業一覧から気になる会社を選びます。
2. 概要・業績・財務・CF・決算・ニュースを確認します。
3. 「売買」から株数を指定し、確認画面を経て購入・売却します。
4. 「次の四半期へ進む」で決算、ニュース、景気、金利、株価が更新されます。
5. 40四半期（10年）の運用後、成績と投資スタイルが表示されます。

## 株価の仕組み

完全なランダムではありません。売上・利益成長、市場予想との差、PERによる期待、景気サイクル、政策金利、業界ニュース、投資家心理を組み合わせ、最後に小さな不確実性を加えています。良い決算でも市場予想を下回れば下落する場合があります。

## 学べる指標

PER、PBR、ROE、ROA、EPS、BPS、売上高、売上総利益、営業利益、経常利益、純利益、営業利益率、自己資本比率、営業CF、フリーCF、配当利回り、配当性向、時価総額、YoY、CAGRを扱います。単一指標で「買い」と判定せず、複数の数字を組み合わせる設計です。

## セーブ

LocalStorageへ保有株、現金、全企業の財務・株価、年月、ニュース、取引履歴、配当、成績を自動保存します。同じブラウザで開けば続きから遊べます。設定画面からリセットできます。

## ファイル構成

- `index.html`：画面構造
- `style.css`：金融端末風ダークUIとレスポンシブ表示
- `game.js`：企業データ、財務計算、決算、株価、売買、セーブ
- `ゲームを起動.html`：ダブルクリック用入口

## 注意
