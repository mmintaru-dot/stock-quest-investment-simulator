# Stock Quest｜株式投資シミュレーター

仮想資金100万円で、日本株・米国株を想定した架空銘柄の売買を体験できる初心者向けブラウザゲームです。

## 起動方法

`ゲームを起動.html` をダブルクリックしてください。インターネット接続やインストールは不要です。

## 主な機能

- 8つの仮想銘柄、ランダムな経済ニュースと株価変動
- 購入・売却、平均取得単価、実現・含み損益、売買履歴
- 総資産と株価のチャート、最大ドローダウン、リスク評価
- 20語の投資用語集、投資クイズ、ポイント、実績とランク
- 初心者・標準・チャレンジの3難易度
- localStorageによる自動保存、スマートフォン対応

※教育目的の架空シミュレーションであり、実際の投資判断には利用できません。
